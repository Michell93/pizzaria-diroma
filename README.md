# 🍕 Pizzaria Di Roma

Site institucional da **Pizzaria Di Roma**, desenvolvido com **HTML, CSS e Bootstrap**.  
O projeto inclui carrossel de imagens, cardápio, equipe, depoimentos, formulário de contato e mapa de localização.

---

## 🚀 Demonstração

🔗 [Acesse o site online](https://Michell93.github.io/pizzaria-diroma/)

## 🖼️ Funcionalidades

- ✅ **Carrossel** com imagens e chamadas para ação  
- ✅ **Seção de serviços** com ícones  
- ✅ **Cardápio** com pizzas e preços  
- ✅ **Equipe** com fotos dos pizzaiolos  
- ✅ **Depoimentos** em carrossel  
- ✅ **Formulário de contato**  
- ✅ **Mapa de localização** via Google Maps  
- ✅ **Rodapé** com redes sociais e horário de funcionamento  

---

## ⚙️ Tecnologias Utilizadas

- [Bootstrap 5](https://getbootstrap.com/)  
- [Font Awesome](https://fontawesome.com/)  
- HTML5 + CSS3

## 📌 Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Michell93/pizzaria-diroma.git
   ```
2. Entre na pasta:
   ```bash
   cd pizzaria-diroma
    ```
3. Abra o arquivo index.html no navegador.

🌐 Publicação no GitHub PagesEste projeto está publicado no GitHub Pages.
Para atualizar o site online, basta fazer alterações e rodar:
   ```bash
   git add .
   git commit -m "Atualização do site"
   git push
   ```
